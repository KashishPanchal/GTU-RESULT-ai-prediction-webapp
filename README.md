# GTU AI Result Predictor

An AI-powered web application designed to help Gujarat Technological University (GTU) students estimate their expected academic performance and exam readiness based on academic and study-related inputs.

## Overview

The **GTU AI Result Predictor** uses a machine learning classification pipeline to predict a student's expected GTU grade and provide an estimated pass probability, confidence score, performance category, strengths, weaknesses, and subject-specific study recommendations.

The application is built with **Python, Flask, Pandas, NumPy, and Scikit-learn**, with **SQLite** used for storing subject information and prediction history.

## Key Features

- 🎓 GTU-focused academic result prediction
- 📊 Predicts expected grades:
  - AA
  - AB
  - BB
  - BC
  - CC
  - CD
  - DD
  - FF
- 📈 Estimated pass probability
- 🤖 Machine learning prediction with confidence score
- 🧠 Academic strengths and weaknesses analysis
- 📚 Subject-specific revision recommendations
- 🏫 Department and semester-based subject selection
- 📝 Supports different assessment stages:
  - Before Mid-1
  - After Mid-1
  - After Mid-2
- 📋 Prediction history stored in SQLite
- 🗑️ Ability to delete prediction history
- 🔌 REST API endpoints for application functionality
- 📱 Responsive web interface using HTML, CSS, and JavaScript

## How It Works

The prediction system uses the following student information:

- Department
- Semester
- Subject
- Assessment stage
- Attendance percentage
- Previous semester SPI
- Weekly study hours
- Active backlogs
- Mid-1 marks, when applicable
- Mid-2 marks, when applicable

The trained machine learning pipeline processes these inputs and predicts the expected GTU grade.

## Machine Learning

The project evaluates multiple classification algorithms:

- Random Forest Classifier
- Extra Trees Classifier
- HistGradientBoosting Classifier

The training pipeline uses:

- One-Hot Encoding for categorical features
- Missing-value imputation for numerical features
- Standard scaling for numerical features
- 80/20 train-test split
- 5-fold cross-validation
- Accuracy, Precision, Recall, Macro F1-score, and confusion matrix evaluation

The best-performing model is selected based on test-set Macro F1-score and saved as a serialized `.joblib` model.

## Dataset

The project includes a GTU-focused dataset generated by `generate_dataset.py`.

The dataset generator creates synthetic academic records using correlations between:

- SPI
- Attendance
- Study hours
- Active backlogs
- Mid-1 marks
- Mid-2 marks
- Subject difficulty

The generated data is intended for application development and machine learning experimentation and should not be treated as official GTU student records.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/KashishPanchal/GTU-RESULT-ai-prediction-webapp.git
cd GTU-RESULT-ai-prediction-webapp
```

### 2. Create a virtual environment

Windows:

```powershell
py -3.11 -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## Running the Application

Start the Flask application:

```bash
python app.py
```

The application will run at:

```text
http://127.0.0.1:5000
```

Open the address in a web browser to use the application.

## Retraining the Model

To generate a fresh synthetic dataset:

```bash
python generate_dataset.py
```

Then train and evaluate the machine learning models:

```bash
python train_model.py
```

The selected model will be saved to:

```text
models/gtu_grade_model.joblib
```

and its metadata will be saved to:

```text
models/model_metadata.json
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/status` | Check application status |
| GET | `/api/departments` | Get available departments |
| GET | `/api/semesters` | Get supported semesters |
| GET | `/api/subjects` | Get subjects by department and semester |
| GET | `/api/subject/<subject_code>` | Get subject details |
| POST | `/api/predict` | Generate a result prediction |
| GET | `/api/history` | View prediction history |
| DELETE | `/api/history/<id>` | Delete a prediction record |
